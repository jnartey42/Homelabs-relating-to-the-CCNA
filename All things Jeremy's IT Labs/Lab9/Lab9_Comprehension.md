Configuring Interfaces

Jeremy's IT Labs on YouTube

--------

Comprehension: The lab and video references Jeremy's Day 9 (Switch Interfaces) video pertaining to the CCNA. Jeremy discusses how interfaces on a switch works (layer 1) of the TCP layer model. He discusses what's different between interfaces on a switch, in comparison to a router which was discussed earlier in his series. Switches often have more interfaces to work with. He goes through various commands that one can use on the Cisco CLI, such as `show ip interfaces brief`, which shows a table featuring information such as the interface, IP address (even though its a switch, they will all remain unassigned because it works at Layer 2 of the TCP model), and configuration status of whether its operational, and its status. Switch interfaces don't have the shutdown command enabled by default. Jeremy talks about the importance of full and half duplex operation (whether devices are allowed to process and send data at the same time, or do each operation one by one), why CSMA/CD (Carrier Sense Multiple Access with Collision Detection) is important, how interfaces negotiate internet speeds, and possible errors that can occur as an interface tries to send out data.

Lab: Question 1 is simply asking to configure the hostname of the devices, which is straightforward enough. Entering the Cisco CLI, utilizing priviledged exec mode, and using the `hostname` command to modify the name of each of the devices to what's being asked (`R1` for the Router, `SW1` and `SW2`, one for each of the switches in the network topology. Question 2 is asking to configure the IP addresses of each device in the topology. In Cisco Packet Tracer, you can modify a PC's IP address by clicking on it, and changing it by clicking Config > FastEthernet0. One can also do this through a series of commands in the command line, which is done in later labs on more complex topics. In R1's CLI, I checked to make sure the interfaces were configured correctly, and were up and running. Question 3 simply dealt with configuring the speed and duplex on the switch interfaces, which can be done with commands like `speed 100` and `duplex auto`, allowing high internet speeds, and enabling full-duplex, so that data can be sent and received at the same time, rather than only being limited to one action at a time. Question 4 asks us to configure descriptions on the interfaces, which is done by the `description` command. The last question mentions disabling interfaces that aren't connected to other devices. The simplest way of going about this is by controlling a specified interface range with `int range f#/# - ##`, and writing an appropriate description. Follow this up by shutting down these interfaces with `shutdown`.
